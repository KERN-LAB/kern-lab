## 03 / Current Project

### TRUSTLINES — Cybersecurity Research Lab

An independent experimental laboratory designed for
hands-on learning, controlled security testing and
reproducible technical research.

**Status:** In development.

The laboratory explores the relationship between
offensive security, defensive mechanisms, software
engineering and system architecture.

## 04 / Methodology

Research → Hypothesis → Experiment → Evidence →
Analysis → Documentation

- Understand mechanisms before using tools.
- Build, investigate and question assumptions.
- Develop independent problem-solving skills.
- Document reproducible experiments.
- Learn from failures and unexpected results.

## 05 / Research Principles

All security testing is conducted within controlled
environments, personal laboratories or explicitly
authorized systems.

Committed to ethical security research, responsible
disclosure and technical integrity.
